# odin-landing-page

A landing page sketch for **Human Protocol**, an early draft of an open framework built on human dignity, nonviolence and accountable power. This is a work in progress and a study project, not the official site.

Built as the Landing Page project of [The Odin Project](https://www.theodinproject.com/lessons/foundations-landing-page) Foundations course.

## Live site

https://degasdegani.github.io/odin-landing-page/

## Built with

- HTML
- CSS (flexbox, a single stylesheet)
